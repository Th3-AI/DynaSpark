Getting Started

Overview

The DynaSpark API provides powerful AI capabilities for text generation, image creation, and audio synthesis. It's designed to be easy to use while offering advanced features for developers.

Note: Currently, no API key is required for testing and development. You can use the API without authentication.

Authentication

While authentication is optional, you can include an API key in your requests:

curl -X POST "https://dynaspark.onrender.com/api/generate" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Hello, world!"}'

Base URL

All API endpoints are relative to the base URL:

https://dynaspark.onrender.com/api

Endpoints

Text Generation

POST /generate

Generate text responses using various models and parameters.

Request Body:

Parameter Type Description Default
prompt string The input text to generate a response for Required
model string Model to use for generation None
temperature float Controls randomness (0.0-3.0) 0.8
top_p float Controls diversity (0.0-1.0) 0.9
presence_penalty float Penalizes repeated tokens (-2.0-2.0) 0.0
frequency_penalty float Penalizes frequent tokens (-2.0-2.0) 0.0

Example Request:

curl -X POST "https://dynaspark.onrender.com/api/generate" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "What is artificial intelligence?",
    "model": "mistral",
    "temperature": 0.8,
    "top_p": 0.9
  }'

Image Generation

POST /generate-image

Generate images from text descriptions.

Request Body:

Parameter Type Description Default
prompt string The prompt to generate an image for Required
width integer Image width (64-2048) 768
height integer Image height (64-2048) 768
model string Model to use (flux/turbo/gptimage) flux
nologo boolean Exclude watermark false
wm string Custom watermark text null

Example Request:

curl -X POST "https://dynaspark.onrender.com/api/generate-image" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A serene mountain landscape",
    "width": 1024,
    "height": 768,
    "model": "flux",
    "nologo": true
  }'

Audio Generation

POST /generate-audio

Generate audio responses from text using various voices.

Request Body:

Parameter Type Description Default
text string The text to convert to speech Required
voice string Voice to use alloy

Available Voices:

Voice Description
alloy Balanced, natural-sounding voice (default)
echo Clear, professional voice
fable Warm, engaging voice
onyx Deep, authoritative voice
nova Bright, energetic voice
shimmer Soft, melodic voice

Example Request:

curl -X POST "https://dynaspark.onrender.com/api/generate-audio" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello, this is a test!",
    "voice": "nova"
  }'

Error Handling

The API uses standard HTTP status codes and returns error details in the response body:

Status Code Description
400 Bad Request - Invalid parameters
401 Unauthorized - Invalid API key
429 Too Many Requests - Rate limit exceeded
500 Internal Server Error

Error Response Example:

{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Rate limit exceeded. Try again in 60 seconds.",
    "details": {
      "reset_time": "2024-01-01T00:01:00Z"
    }
  }
}

Rate Limits

The API implements rate limiting to ensure fair usage:

Free Tier Limits

  • 100 requests per hour
  • Maximum 10 concurrent requests
  • Rate limit headers included in responses

Rate Limit Headers

Header Description
X-RateLimit-Limit Total requests allowed per hour
X-RateLimit-Remaining Remaining requests in current hour
X-RateLimit-Reset Time when rate limit resets (Unix timestamp)

Basic Audio:

  -H "Content-Type: application/json" \
  -d '{
    "text": "Welcome to DynaSpark! This is a test of the audio generation.",
    "voice": "alloy"

Multiple Voices:

# Generate audio with different voices
for voice in "alloy" "echo" "nova"; do
  curl -X POST "https://dynaspark.onrender.com/api/generate-audio" \
    -H "Content-Type: application/json" \
    -d "{
      \"text\": \"This is voice $voice\",
      \"voice\": \"$voice\"
    }" > "voice_${voice}.mp3"
done

Troubleshooting

Common Issues

Rate Limit Exceeded

If you see a rate limit error, wait for the reset time or reduce your request frequency.

Image Generation Fails

If image generation fails, check that your prompt is appropriate and within the allowed parameters.

Audio Generation Issues

If audio generation fails, ensure your text is not too long and contains valid characters.

FAQ

Frequently Asked Questions

Do I need an API key?

No, currently no API key is required to use the API. You can start using it right away!

What are the rate limits?

Free usage is limited to 100 requests per hour. Contact us for higher limits.

Can I use this in production?

Yes, the API is stable and suitable for production use. However, consider getting a custom API key for higher rate limits.
